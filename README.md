<h1 align="center">Blossom · Friday Dev Call</h1>

<p align="center">
  <strong><a href="https://blossom-ag.github.io/blossom-friday-dev-call/">Open the live agenda →</a></strong>
</p>

The clickable agenda for the weekly Friday developer call. Run it top to bottom and check items off as you go.

1. **Stand-up.** Each developer (Frans, Jeremy) covers what they did yesterday, what they're doing today, and anything blocking them.
2. **Every week.** The routine items, in this order: Triage → in-flight review → review queue → next-cycle planning → estimates → status hygiene → close-out → initiatives & projects health. Estimates use the Fibonacci scale (1–21).
3. **Open items.** Add topics during the week with the box on the page. Unchecked items carry over to the next Friday; checked ones are archived when you tap **Finish & save**.

- ✅ Clickable rows and a progress bar.
- 🗓️ Checks clear automatically each new week.
- 💾 **Finish & save** keeps a **Past weeks** history.
- 📴 No login and no backend. Everything saves in the browser on the device you use, so add open items on the same computer you run the call from.

Monday prep (initiative health and scorecard numbers) lives at [Monday Prep](https://blossom-ag.github.io/blossom-monday-checklist/).
